# Demand Prediction with Machine Learning

## What problem does this solve?
Ordering too much wastes money. Ordering too little causes stockouts and
lost sales. This project uses machine learning to predict next month's demand
for a product, so ordering can be more accurate.

## What data / tools did I use?
- Python, pandas, NumPy, scikit-learn
- Jupyter Notebook / Google Colab
- Historical sales / demand data (date, product, quantity sold, price, stock)

## What did I do?
1. Cleaned and prepared the data for modelling
2. Split the data into training and testing sets
3. Trained a model (Linear Regression / Random Forest)
4. Evaluated the model using MAE / RMSE and compared predictions vs actuals
5. Explained what the prediction means for ordering decisions
